บทที่ 5 : แกว่งกวัด & SHM Oscillations
นิยามคาบ: $T = \frac{1}{f} = \frac{2\pi}{\omega}, \quad \omega = 2\pi f$
สมการ SHM: $x = A\sin(\omega t+\phi)$ [$x=0 \to v_{\max}$]
ความเร็ว: $v = \omega A\cos(\omega t+\phi) = \pm\omega\sqrt{A^2-x^2}$
ความเร่ง: $a = -\omega^2 x, \quad a_{\max} = \omega^2 A$ [$x=\pm A$]
สปริง: $\omega = \sqrt{\frac{k}{m}}, \quad T = 2\pi\sqrt{\frac{m}{k}}$
พลังงาน: $E = \frac{1}{2}kA^2 = \frac{1}{2}mv^2 + \frac{1}{2}kx^2$ (คงที่)
Simple: $T = 2\pi\sqrt{\frac{L}{g}}$ (ไม่ขึ้นกับมวล $m$)
Physical: $T = 2\pi\sqrt{\frac{I}{mgd}}$ [$d$ = จุดหมุน $\to$ CM]
Torsion: $\tau = -\kappa\theta, \quad T = 2\pi\sqrt{\frac{I}{\kappa}}$
หน่วง Damped: $A(t) = A_0 e^{-\gamma t}, \quad \gamma = \frac{b}{2m}$
สภาวะหน่วง: $\omega' = \sqrt{\omega_0^2-\gamma^2}$ เกิน($>$), วิกฤต($=$), น้อย($<$)
สั่นพ้อง: $\omega_f = \omega_0 \implies A_{\text{max}}$ (Resonance)
บทที่ 6 : คลื่นและคลื่นเสียง Waves & Sound
คลื่นทั่วไป: $v = f\lambda = \frac{\omega}{k}, \quad k = \frac{2\pi}{\lambda}$
ฟังก์ชันคลื่น: $y = A\sin(kx \mp \omega t)$ [- ขวา, + ซ้าย]
เชือก / น้ำ: $v = \sqrt{\frac{T}{\mu}}$ ($\mu = \frac{m}{L}$), $\quad v_{\text{น้ำ}} = \sqrt{gd}$
ของแข็ง/ไหล: $v = \sqrt{\frac{Y}{\rho}}$ (แข็ง), $\quad v = \sqrt{\frac{B}{\rho}}$ (ไหล)
เสียงในอากาศ: $v = 331 + 0.6T_C \quad [\text{m/s}]$
สเนลล์: $\frac{\sin\theta_1}{\sin\theta_2} = \frac{v_1}{v_2} = \frac{\lambda_1}{\lambda_2} = \frac{n_2}{n_1}$ ($f$ คงที่)
แทรกสอด: ปฏิบัพ: $d\sin\theta = n\lambda$, บัพ: $(n-\frac{1}{2})\lambda$
เชือก/ท่อเปิด: $f_n = \frac{nv}{2L} = n f_1 \quad (n = 1, 2, 3, \dots)$
ท่อปิด 1 ด้าน: $f_n = \frac{nv}{4L} = n f_1 \quad (n = 1, 3, 5, \dots \text{คี่})$
เรโซแนนซ์: $L_2 - L_1 = \frac{\lambda}{2} \implies v = 2(L_2-L_1)f$
เข้ม/ระดับ: $I = \frac{P}{4\pi R^2}, \quad \beta = 10\log\left(\frac{I}{10^{-12}}\right)$
บีตส์: $f_{\text{beat}} = |f_1 - f_2|$ (ติดขี้ผึ้ง $\implies f \downarrow$)
ดอปเปลอร์: $f' = f\left(\frac{v \pm v_o}{v \mp v_s}\right)$ [บน: เข้า+, ล่าง: เข้า-]
Shock wave: $\sin\theta = \frac{v}{v_s}, \quad M = \frac{v_s}{v} = \frac{1}{\sin\theta}$
บทที่ 7 : สมบัติเชิงกลของสารและกลศาสตร์ของไหล Fluids & Matter
เค้น / เครียด: $\sigma = \frac{F}{A}, \quad e = \frac{\Delta L}{L_0}, \quad \gamma \approx \theta = \frac{a}{h}$
ยังมอดูลัส: $Y = \frac{\sigma}{e} = \frac{F L_0}{A \Delta L}, \quad S = \frac{F/A}{\gamma}$
บัลก์มอดูลัส: $B = -\frac{\Delta P}{\Delta V/V_0}$
ความดัน: $P_G = \rho gh, \quad P_{\text{abs}} = P_{\text{atm}} + \rho gh$
หลอดตัวยู: $P_L = P_R \implies \rho_1 h_1 = \rho_2 h_2$
ปาสคาล: $\frac{F_1}{A_1} = \frac{F_2}{A_2} \implies F_2 = F_1\left(\frac{d_2}{d_1}\right)^2$
คานโยก: $F_{\text{hand}} \cdot L = F_1 \cdot l \implies F_1 = F_{\text{hand}}\frac{L}{l}$
แรงลอยตัว: $F_B = \rho_{\text{fluid}} g V_{\text{sub}}, \quad T = mg - F_B$
แรงตึงผิว: ฟิล์ม: $\gamma = \frac{F}{2l}, \quad$ วงกลม: $\gamma = \frac{F}{4\pi r}$
ต่อเนื่อง: $A_1 v_1 = A_2 v_2 = Q$ (ของไหล $\rho$ คงที่)
แบร์นูลลี: $P_1 + \frac{1}{2}\rho v_1^2 + \rho gh_1 = P_2 + \frac{1}{2}\rho v_2^2 + \rho gh_2$
เวนจูรี: $v_1 = \sqrt{\frac{2gh}{(A_1/A_2)^2 - 1}}, \quad F_{\text{lift}} = \frac{1}{2}\rho(v_2^2 - v_1^2)A$
รูรั่วถัง: $v = \sqrt{2gh}, \quad x_{\text{ตก}} = 2\sqrt{h(H-h)}$
สโตกส์: $F_f = 6\pi\eta R v, \quad v_t = \frac{2}{9}\frac{R^2 g}{\eta}(\rho - \rho_0)$
⚡ ทริคกันตายก่อนส่งข้อสอบ: 1) มุม SHM ตรีโกณอยู่ในโหมด RAD เสมอ 2) ท่อปิด 1 ด้านมีเฉพาะฮาร์มอนิก เลขคี่ ($n=1,3,5$) ห้ามใช้ $n=2$ 3) แม่แรงไฮดรอลิกส์ถ้าให้ $d$ ต้อง ยกกำลังสอง $(d_2/d_1)^2$ 4) แรงลอยตัว $F_B$ ใช้ $\rho_{\text{เหลว}}$ และ $V$ เฉพาะส่วนที่จม 5) ค่าคงที่: $P_{\text{atm}} = 1.013\times 10^5\text{ Pa}$, $\rho_{\text{น้ำ}} = 1000\text{ kg/m}^3$
